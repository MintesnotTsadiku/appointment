# Public experience theme-mode validation

This evidence set verifies all five seeded public-site templates in light and dark mode at desktop and mobile viewports.

- `visual-audit.json` records contrast checks and theme-switch persistence.
- `validation-summary.json` records browser console, network, and response failures for Selam and Abugida.
- PNG files are the captured browser pages.
- JPG files compare the light and dark renders side by side.

The audit forces each initial mode, verifies the page's resolved mode, activates the visible mode switch, and confirms the new preference is stored.
