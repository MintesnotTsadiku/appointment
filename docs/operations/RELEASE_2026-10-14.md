## Deployment

Follow [GO_LIVE_RUNBOOK](GO_LIVE_RUNBOOK.md). The steps for this release:

1. Take a backup of the site with files.
2. On the server: `git -C apps/appointment fetch origin && git -C apps/appointment checkout main && git -C apps/appointment pull --ff-only`.
3. Python: `bench setup requirements` (new dependency `openpyxl` for the organization workbook import).
4. Frontend: in `apps/appointment/frontend`, with Node 22 (`.nvmrc`): `npm ci && npm run build`. The build writes `appointment/public/frontend`; `www/index.html` and `www/schedule/index.html` include it. Do not run a bare `bench build` on a shared bench.
5. `bench --site <site> migrate`. It creates the new DocTypes, runs the patches (translation imports, customer profile links, content permissions, provider page slugs) and the after-migrate seeds (brand and growth defaults, directory categories and areas, frontend translations).
6. Restart the bench processes (web, workers, scheduler, socketio).
7. `bench --site <site> execute appointment.ops.go_live.report` and fix every `fail`.

## After deployment: settings to review

- **Platform Brand Settings**: product name, URL, short host, logo, mark, colour, taglines.
- **Growth Settings**: switches for "Powered by" lines, referrals and rewards, directory, tools, year in review, template credit, the "live in N minutes" number.
- **Website Settings → Enable view tracking**, if you want visit counts on the Grow page.
- **Payment Settings**: free bookings, fees, Chapa keys and webhook secret (still needed).
- **SMS**: the AfroMessage token (still needed).
- Guest booking limits: the defaults are 10 per IP and 3 per email per business in 10 minutes. Do not copy the raised development values.

## Decisions still open

1. **Live template preview in the gallery dialog.** Public pages send `X-Frame-Options: DENY` and `frame-ancestors 'none'`, so the dialog shows the screenshot instead of the live site. Allowing same-origin framing for showcase pages only is a security decision.
2. **Independent providers and platform fees.** The fee ledger charges organizations only, so referral credits never apply to independent providers.
3. **Amharic review.** A native reviewer should check the Amharic catalog (more than 1,350 strings, plus the new growth strings).
4. **Not included:** local commit `d82e306` "manage rich demo from settings" (development-only demo controls from 2026-09-23, superseded by the current showcase seeding).

## Rollback

Restore the backup from step 1, check out the previous `main` commit, rebuild the frontend and restart. The new DocTypes stay in the database but are unused by the old code.
