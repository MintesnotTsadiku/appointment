# Planning & Project Management

This folder contains project planning, requirements, and tracking documents.

## Contents

- **PROJECT_SUMMARY.md** - High-level project overview
- **PROJECT_STATUS_TRACKER.md** - Sprint board and progress tracking
- **scheduling_platform_prd.md** - Product requirements document
- **scheduling_platform_implementation_plan_sprint_board.md** - Detailed implementation plan

## When to Use

- **Understanding the project**: Read PROJECT_SUMMARY.md
- **Tracking progress**: Update PROJECT_STATUS_TRACKER.md daily
- **Requirements reference**: Check scheduling_platform_prd.md
- **During development**: Follow scheduling_platform_implementation_plan_sprint_board.md

## Updates

- **PROJECT_STATUS_TRACKER.md**: Update after each sprint/task completion
- **PROJECT_SUMMARY.md**: Update monthly or at major milestones
- **PRD**: Update when requirements change
- **Implementation plan**: Update when architecture changes
