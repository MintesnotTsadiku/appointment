# Landing Page Design Prompt

You are the go-to top 0.1% designer and developer for the world's leading innovation in front-end design and development. You are tasked to create a full landing page with advanced visual effects using WebGL + Three.js in the styling of an uploaded image for the scheduling platform.

**Context:** This is a modern scheduling platform that serves both independent professionals and enterprise teams. Solo providers get shareable booking links, while enterprises use a front-desk console to manage multi-provider, multi-location schedules. The platform features automated availability management, integrated payment processing, SMS/USSD booking capabilities for low-connectivity environments, multi-language localization, and comprehensive data protection compliance.

**What are Dither + Shaders?**
- **Dither**: A visual technique that adds subtle texture/grain to reduce color banding and create depth. In WebGL, it's often used for stylized aesthetics or to add visual interest.
- **Shaders**: GPU programs (written in GLSL) that create custom visual effects like post-processing, particle systems, lighting, distortions, and procedural animations. In Three.js, these enable advanced materials and effects.

**Scheduling Platform Equivalents:**
For a scheduling platform, consider these visual effects instead of traditional dither:
- **Temporal Flow Effects**: Shader-based animations that show time flowing, calendar transitions, or appointment sequences
- **Connection Networks**: Visual effects showing appointments as connected nodes, synchronization pulses, or relationship webs
- **Grid Morphing**: Shader effects that transform calendar grids, showing availability states, or booking flows
- **Depth-Based Layering**: Post-processing effects that create depth, showing multiple time zones or locations as layers
- **Particle Scheduling**: Particle systems representing appointments, reminders, or connections flowing through the interface
- **Smooth Transitions**: Shader-based state changes that reflect seamless booking experiences (loading states, confirmations)

**Design Focus:**
- Focus mainly on the design part, not the development.
- The landing page should communicate: ease of booking, professionalism, reliability, and modern scheduling capabilities
- Visual themes to consider: calendars, time management, connectivity, seamless booking flows, enterprise-grade reliability

**Technical Requirements:**
Import all necessary files and libraries:
- Three.js
- WebGL
- GSAP
- Shader libraries (e.g., Three.js post-processing effects, custom shader materials)
- Any other animation libraries related to 3D development

**Recommended Shader Effects for Scheduling Platform:**
- **Time-based animations**: Flowing timeline visualizations with shader-driven motion
- **Network/connection shaders**: Visualizing appointment relationships and provider connections
- **Grid-based effects**: Calendar grid morphing, availability heatmaps, or booking state transitions
- **Particle systems**: Representing appointments, notifications, or data flow
- **Post-processing**: Bloom effects for highlights, depth of field, or color grading to enhance mood
- **Procedural patterns**: Generating calendar-like patterns, time-based textures, or organizational structures

**Design Elements to Emphasize:**
- Time and scheduling visualizations (abstract calendar grids, flowing timelines)
- Connection and synchronization metaphors (networks, linked nodes)
- Professional yet approachable aesthetics
- Smooth, fluid animations that reflect the seamless booking experience
- Modern, clean interface elements that communicate trust and reliability
